# Жизненный цикл сессии

Обозначения — в [overview.md](overview.md#как-читать-документы).

```
Клиент                                   Сервер
  │  TCP connect :5190                      │
  │──── pg ────────────────────────────────▶│  (каждые 20 с, без ответа)
  │──── lg|login|password| ────────────────▶│
  │                                         │
  │◀─── lf|code ────────────────────────────│  ошибка входа, конец
  │   или                                   │
  │◀─── cc|sex ─────────────────────────────│  персонажа нет → создание
  │──── cc|appearance|avatar|stats…|skills|perk|
  │   или                                   │
  │◀─── 0v, ss, 0g, 0m, … ──────────────────│  начальное состояние
  │◀─── ls ─────────────────────────────────│  вход разрешён
  │   (клиент грузит ресурсы)               │
  │──── eg ────────────────────────────────▶│  войти в мир
  │◀─── ch, zc, vh, lg, nw, sb, ul, 1e, lp, 17, ss… │
  │   … игра …                              │
```

## Логин

**C→S** `lg|<login>|<password>|` — обычный вход (`FightSocket.loginFight`).
**C→S** `0n|<type>|<id>|<token>` — вход через соцсеть (`FightSocket.loginFight`, данные `obj57` от `SocialApi`).

**S→C** `lf|<code>` — отказ:

| code | Константа | Сообщение |
|---|---|---|
| 0 | `ERROR_WRONG_LOGIN` | `IDS_WRONG_LOGIN` |
| 1 | `ERROR_USER_ONLINE` | `IDS_USER_ONLINE` |
| 2 | `ERROR_BANNED` | `IDS_LOGIN_BANNED` (форма входа снова активна, соц-вход сбрасывается) |
| 6 | `ERROR_TO_MANY_TRIES` | `IDS_WAIT_15_SECS` |

**S→C** `ls` — логин принят. Клиент запускает загрузку ресурсов (`Main.dataStartGame` → `EnterPage.moveIn`), затем создаёт мир и отправляет `eg`.

**S→C** `cc|<sex>` — у аккаунта нет персонажа. Клиент загружает ресурсы и открывает окно создания персонажа. После выбора отправляется
`cc|<appearance>|<avatar>|<stat0>|…|<stat5>|<skillsMask>|<perk>|` (`CharacterMenu.charDone`).

## Вход в мир

**C→S** `eg` — войти в игровой мир (`GameSocket.enterGame`, вызывается после загрузки).

**S→C** `eg` — подтверждение входа. Приходит после `lg`, но раньше `ul` со своим персонажем, пока `gameStarted` ещё `false`, поэтому клиент его игнорирует. При открытом терминале тот же код закрывает терминал ([терминал](terminal.md#команды-сервера-sc)).

Ответ сервера — пакет состояния. Ключевое сообщение — **S→C `lg`** (полное состояние персонажа). Его обрабатывают два обработчика: `Main.dataLogin` и `FightSocket.handleData`.

| Индекс | Поле | Пример |
|---|---|---|
| 1 | время сервера `Y.M.D.h.m.s`, месяц с нуля (как в JS `Date`) | `2026.9.27.15.8.9` |
| 2 | sessionId своего персонажа (id в мире) | `3006` |
| 3, 4 | ширина и высота карты в клетках | `4000`, `4000` |
| 5 | флаги терминала: 0 — в мире; иначе `channel << 1 \| bit` и клиент открывает терминал | `0` |
| 6 | права пользователя (битовая маска, `Character.hasAccess`) | `0` |
| 7, 8 | тип и значение аддона (прибора: счётчик Гейгера, детектор и т.п.) | `0`, `0` |
| 9, 10 | расход и пополнение запаса бега (×2), см. [бег](movement.md#бег) | `3630`, `4491` |
| 11 | текущий вес груза, г | `4396` |
| 12 | максимальный переносимый вес, г. Клиент пропускает поле и рассчитывает вес самостоятельно (`Character.MaxWeight`): `(40 + 3·сила + 4·выносливость)·1000`, +15000 после 8-го уровня, бонусы перков, +0.05 × навык торговли | `109000` |
| 13, 14, 15 | опыт, опыт начала уровня, опыт следующего уровня | `522`, `300`, `1000` |
| 16 | клиент не читает | `0` |
| 17 | активная рука (0/1) | `0` |
| 18–22 | оружие 0: тип, патроны в запасе, заряд магазина, режим огня, тип патронов | |
| 23–27 | оружие 1: то же | |
| 28 | клиент не читает | `0` |
| 29… | «полная информация о персонаже» ([информация о персонаже](data-structures.md#информация-о-персонаже)) | |
| далее | панель расходников: 10 × `imageId\|name\|count` ([быстрые слоты](data-structures.md#быстрые-слоты-расходников)) | |

Пример последовательности после `eg`.

```
0v|1|5|9|           ch|...           zc|Респаун|...|1|4    vh|...
lg|...              nw|...           sb|...                ul|...
1e|                 zc|...           lp|...                17|skip@skip.sp|
0v|1|5|9|           ss|0|0
```

## Терминал

Персонаж может находиться в мире или в «терминале» (меню-локации: кланы, обмен, найм, рейды и т.п.).

- **S→C** `et|<flags>` в мире: очистить мир и чат, открыть терминал. `flags >> 1` — номер канала терминала, `flags & 1` — дополнительный флаг (`Terminal.isValue38`).
- **C→S** `ex` — выйти из терминала. Ответ **S→C** `eg` (в режиме терминала) → показать мир.

## Завершение

Специальной команды выхода нет. Клиент просто закрывает соединение (закрытием страницы).
