## Как читать документы

- **C→S** — сообщение от клиента серверу, **S→C** — от сервера клиенту.
- В форматах `|` разделяет поля, `[...]` — необязательная часть, `{...}×N` — группа полей, повторённая N раз.
  Имя поля описывает, что клиент делает с этим значением.
- «?» обозначает поле неизвестного назначения, «-» обозначает поле, которое клиент пропускает.

## Общие сведения

| Параметр | Значение |
|---|---|
| Сервер | `unit-online.ru` |
| Порт | `5190` (TCP) |
| Резервный канал | HTTP POST `http://unit-online.ru/webrule.fcgi` |
| Кодировка | Windows-1251 в обе стороны |
| Формат | текстовые команды, поля разделены `\|` |
| Код команды | первое поле, обычно из двух символов набора `[0-9a-z]` |
| Шифрование и сжатие | отсутствуют, пароль передаётся открытым текстом |

Протокол асимметричен: клиент отправляет сообщения с бинарным префиксом длины, сервер — текст с терминатором `#`.

## Маршрутизация входящих сообщений

- **До получения `lg`** клиент обрабатывает только `lg`, `ls`, `eg`, `cc`, `lf`, `hn`, `cl`, `cd`, `es`, `ch`, `ss`, `0g`, `0m`, `0q` и `17`. Прочие сообщения в этой фазе, включая `vh` и `0v`, отбрасываются.
- **В терминале** часть кодов имеет своё значение. Например, `ul` передаёт список пользователей терминала, `iv` открывает инвентарь терминала, а `eg` закрывает терминал и показывает мир. См. [команды терминала](terminal.md#команды-сервера-sc).
- **В мире** клиент обрабатывает карту, существ, инвентарь, диалоги и другие игровые состояния. См. [команды сервера](server-commands.md) и [числовые команды](numeric-commands.md).
